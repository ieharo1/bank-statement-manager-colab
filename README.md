# 🏦 Bank Statement Manager (Google Colab)

Herramienta automatizada para parsear, almacenar y analizar estados de cuenta bancarios de bancos ecuatorianos desarrollada por **Isaac Esteban Haro Torres**.

---

## 📝 Descripción

Sistema automatizado que permite subir múltiples estados de cuenta en PDF, parsearlos automáticamente, almacenarlos en SQLite y generar análisis financiero.

---

## ✨ Características

- Subida de múltiples PDFs de estados de cuenta
- Parseo automático de Banco del Austro y Banco del Pacífico
- Soporte OCR para PDFs escaneados
- Normalización y limpieza de datos
- Almacenamiento en base de datos SQLite
- Tablas de resumen financiero y cálculos de intereses
- Simulador de pagos para calcular meses para pagar deuda

---

## 🛠️ Stack Tecnológico

- Google Colab
- Python
- SQLite
- OCR (Tesseract)
- Pandas
